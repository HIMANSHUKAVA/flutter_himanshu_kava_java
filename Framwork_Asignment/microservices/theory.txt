5) What is a load balancer in microservices?

A load balancer distributes incoming requests across multiple service instances.
Example: If user-service has 3 instances running, the load balancer will send requests to different instances.
Tools: Ribbon (deprecated), Spring Cloud LoadBalancer, Nginx, Kubernetes Service.

7) Can 2 microservices have the same database?

Theoretically yes, but in practice  not recommended.
Each microservice should have its own database to remain independent.
But in legacy systems, 2 services may share one database if needed.

8) What is Eureka in microservices?


Eureka is Netflix’s Service Discovery Server.

Services register themselves in Eureka.

Other services fetch service details from Eureka to connect.

Helps in dynamic scaling and load balancing.
